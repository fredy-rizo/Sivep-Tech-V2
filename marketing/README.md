# 📁 Carpeta Marketing — SIVEP Tech

Estructura:
```
/marketing/
  README.md                 ← este archivo
  dia1/                     ← Publicación del Día 1 (teaser / intriga)
    post_teaser.png         ← Imagen de la publicación (PNG)
    copy_publicacion.md     ← Texto completo: descripción + hashtags + CTA
  dia2/                     ← Publicación del Día 2 (cuando se pida)
  ...
```

Cada subcarpeta `diaX` contiene:
- `post_teaser.png`: imagen lista para publicar (formato PNG)
- `copy_publicacion.md`: descripción del post, hashtags y CTA

Regla de operación: nunca publicar sin el CTA único → comentar "DEMO" para agenda de demo privada.
